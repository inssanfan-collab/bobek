# Bobegim — портал детских садов Актюбинской области

Мультисайтовая платформа: один портал плюс отдельный сайт с админкой для каждого
детского сада. Тариф 20 000 ₸/год. Продаётся садам Актобе, деплоится на VPS в РК.

Язык интерфейса, документации, комментариев и коммитов — **русский**.

## Команды

```bash
pnpm db:up        # PostgreSQL в Docker (порт 5433, не 5432)
pnpm db:setup     # миграции + демо-сады
pnpm dev          # разработка
pnpm typecheck && pnpm lint
pnpm test         # 44 юнит-теста (vitest)
pnpm test:e2e     # 34 сквозных (playwright, поднимает сервер сам)
```

Открывать **http://bobegim.local:3000**, не `localhost` — сад определяется по домену.
Домены прописаны в hosts: `bobegim.local`, `sad12.bobegim.local`, `kunshuaq.bobegim.local`,
`ertegi.bobegim.local`.

Доступы после `pnpm db:setup`: портал `admin` / `admin-bobegim-2026`,
сад `sad12-admin` / `sad12-2026`.

## Как устроено

Одно приложение обслуживает портал, сайты всех садов и обе админки.

`src/middleware.ts` смотрит на заголовок Host: домен портала идёт в группу `(portal)`,
любой другой переписывается в `/s/<host>/...` — группу `(tenant)`. И поддомен сада,
и купленный садом собственный домен лежат в одной таблице `Domain`, поэтому путь
резолва один на оба случая.

Изоляция данных — `src/server/db/scope.ts`: репозиторий, который физически не умеет
обратиться к контенту без `tenantId`. **Прямые вызовы `prisma.post`, `prisma.media`
и подобных в коде сайта и админки сада запрещены** — только через `scoped(tenantId)`.
Для update/delete есть `assertOwned()`.

## Грабли, на которые уже наступали

Каждая стоила часа отладки. Не повторяйте.

**`redirect()` из server action не проходит через middleware.** Путь вроде
`/admin/posts` разрешается в маршруты портала, а не сада, и сотрудник получает 404.
Поэтому действия возвращают `{ redirectTo }` (см. `src/lib/action-state.ts`),
а переход делает клиент через `ActionForm` / `window.location.assign`.

**Cookie сессии привязана к домену.** Поэтому «Войти как сад» не может просто
поставить её на портале: сессия передаётся одноразовым токеном через
`/admin/enter` и там же ротируется.

**`COOKIE_SECURE=false` обязателен при работе по http.** Иначе браузер молча
отбрасывает cookie, и вход выглядит как «неверный пароль».

**Внутренний префикс `/s/` заблокирован в middleware.** Без этого с домена портала
открывался бы сайт любого сада по чужому адресу.

**Сырой SQL обходит `scoped()`.** Поиск построен на tsvector, а значит на
`$queryRaw` — единственном месте, где можно случайно прочитать чужой сад.
Поэтому запросы поиска живут в `src/server/db/search.ts`, где `tenantId`
подставляется параметром, а наружу торчит только `scoped(tenantId).search()`.

**Генерируемую колонку Prisma норовит сломать.** У `searchVector` в схеме стоит
`@default(dbgenerated())`: без него `prisma migrate dev` видит `GENERATED ALWAYS AS`
как обычный DEFAULT, генерирует лишнюю миграцию с `DROP DEFAULT` и падает на ней.

**После `prisma migrate dev` перезапустите `pnpm dev`.** Работающий сервер держит
в памяти прежний клиент Prisma, и новое поле схемы даёт `Unknown argument` —
выглядит как ошибка в коде, хотя на диске клиент уже перегенерирован.

**База проекта на порту 5433.** На машинах разработчиков часто уже стоит свой
PostgreSQL на 5432, и Prisma молча подключается к нему.

**`.env` вне репозитория.** `git pull` его не обновляет — после изменения
`.env.local.example` файл нужно перезаписать вручную.

## Соглашения

- **Двуязычие.** У текстовых полей пары `...Kk` / `...Ru`. Вывод через `pick(locale, kk, ru)` —
  если перевода нет, показывается второй язык. Требование закона РК «О языках».
- **HTML от пользователя** санитизируется при сохранении (`sanitizeContent`), не при выводе.
- **Изображения** проходят через `saveUpload` — пересжатие в WebP и снятие EXIF
  (иначе с фото детей уезжают GPS-координаты сада).
- **Аудит.** Сброс паролей, вход «под садом», смена статусов пишутся через `audit()`.
- **Подписка.** После истечения 30 дней сайт работает, админка только на чтение;
  проверять через `assertCanEdit(session)`.
- **Поиск** — полнотекстовый, на генерируемых базой колонках `searchVector`
  (миграция `fulltext_search`). Словаря казахского в PostgreSQL нет, поэтому текст
  индексируется дважды: конфигурацией `russian` (по основе слова) и `simple`
  (как есть), а запрос ищется и по основе, и по началу слова — `наурыз:*`.
  Разбор запроса и подсветка найденного — `src/lib/search-query.ts`. Фрагмент
  приходит из `ts_headline` размеченным управляющими символами, а не готовым HTML:
  собранную из текста сада разметку в страницу не подставляем.
- **Карты.** Координаты сада определяет геокодер Яндекса при сохранении профиля
  (`src/server/maps/yandex.ts`, ключ в `YANDEX_GEOCODER_KEY`) — заведующая своих
  координат не знает. Введённые руками не затираются: одинаковых названий улиц
  в Актобе хватает, и точнее человека геокодер не будет. Сады, заведённые раньше,
  доберёт `pnpm maps:geocode`. Сама карта — виджет Яндекса в iframe, ключа
  не требует; на сайте сада по-прежнему 2ГИС (`RouteMap`).
- **Карта каталога** интерактивная, если задан `YANDEX_MAPS_KEY` (JavaScript API
  2.1, ключ уезжает в браузер), и виджетом в iframe — если нет. Метки
  пронумерованы так же, как карточки. У бесплатного тарифа 100 запросов
  в сутки, поэтому карта строится по нажатию, а не на каждый заход: иначе
  сотня родителей израсходовала бы лимит, и сто первый увидел бы пустое место.
  Запасной виджет по той же причине — не формальность.
- **SEO.** `robots.txt` и `sitemap.xml` есть и у портала, и у каждого сада —
  какой отдать, решает домен. В карте портала нет `hreflang`: портал
  существует только по-русски, в отличие от сайтов садов.
- **Язык админки** хранится в `User.locale`, а не в cookie: заведующая заходит
  с разных устройств, и выбор должен ехать за ней. Переключатель — в шапке
  (`AdminLocaleSwitch`), после смены клиент делает `router.refresh()`. Полная
  перезагрузка тут не годится: она обрывает начатые переходы. Тексты интерфейса
  живут рядом с разметкой словарём `const T = { ключ: { kk, ru } }` — тем же,
  что на сайтах садов. На странице входа пользователя ещё нет, поэтому там язык
  берётся из адреса (`?lang=kk`), как на публичной части.
- **Подписи перечислений и даты** — `src/lib/labels.ts`. `formatDate`,
  `formatDateTime` и `formatAgeRange` принимают язык вторым аргументом;
  по-казахски год идёт первым — «2026 жылғы 3 қыркүйек». Прежние русские
  константы (`KIND_LABEL`, `DOC_CATEGORY_LABEL` и прочие) ещё живут рядом
  с двуязычными: их используют непереведённые экраны портала.
- **Язык портала** — в адресе (`?lang=kk`), как на сайтах садов. Шапка и подвал
  живут в `PortalChrome` и вставляются самими страницами: layout в Next
  не получает searchParams. Cookie было бы проще, но тогда поисковик увидел бы
  одну версию страницы вместо двух.
- Разделы сайта описаны в `src/lib/sections.ts`, шаблоны — в `src/lib/templates.ts`.

## Ограничения предметной области

- Домен `.kz` обязан указывать на сервер **в Казахстане**, иначе регистратор
  приостановит его через 10 дней. Персональные данные тоже должны храниться в РК.
- Очередь в сад ведёт государство через egov.kz — мы на неё только ссылаемся.
  Реализовывать свою нельзя: попадём под требования к государственным системам.

## Чего пока нет

Онлайн-оплата (модель подписки готова, эквайринг подключается без переделки).
Карт на сайтах самих садов две разных — 2ГИС в `RouteMap` и Яндекс в каталоге;
свести к одной мешает то, что ключ JS API ограничен по домену, а у каждого сада
домен свой.
