# Bobegim — портал детских садов Актюбинской области

Мультисайтовая платформа: один портал плюс отдельный сайт с админкой для каждого
детского сада. Сад получает адрес вида `sad12.bobegim.kz`, готовый движок и
панель наполнения. Тариф — 20 000 ₸ в год.

## Что внутри

- **Портал** — каталог садов Актобе с фильтрами, раздел для родителей, тарифы, заявки.
- **Админка портала** — создание садов мастером из 5 шагов с выдачей памятки доступа,
  домены, пользователи, подписки, журнал действий.
- **Сайт сада** — новости, объявления, фотогалерея, документы, педагоги, группы,
  меню питания, свободные места, виртуальная приёмная, контакты.
- **Админка сада** — наполнение всех разделов, выбор шаблона и палитры,
  обращения родителей.

Два языка (қазақша и русский), версия для слабовидящих, mobile-first.

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind · Prisma · PostgreSQL 16 ·
Docker Compose · Caddy.

Одно приложение обслуживает портал, сайты всех садов и обе админки. Сад определяется
по домену в `src/middleware.ts`; изоляция данных — через `src/server/db/scope.ts`,
репозиторий, который не умеет обращаться к контенту без `tenantId`.

## Быстрый старт

```bash
pnpm install
cp .env.example .env          # PORTAL_DOMAIN=bobegim.local для локальной работы
pnpm exec prisma migrate dev
pnpm exec tsx prisma/seed.ts
pnpm dev
```

Добавьте в `/etc/hosts`:

```
127.0.0.1 bobegim.local sad12.bobegim.local kunshuaq.bobegim.local ertegi.bobegim.local demo-sad.bobegim.local
```

Открывайте `http://bobegim.local:3000` — на `localhost` приложение не найдёт сад
и покажет 404, потому что определяет его по домену.

## Тесты

```bash
pnpm test        # юнит: резолв доменов, языки, санитайзер HTML, адреса страниц
pnpm test:e2e    # сквозные: изоляция садов, вход, публикация, создание сада
```

## Важное ограничение

Домен `.kz` обязан указывать на сервер, физически расположенный в Казахстане, иначе
регистратор приостановит его через 10 дней. Персональные данные по закону РК тоже
должны храниться в стране. Поэтому VPS — только у казахстанского провайдера.
