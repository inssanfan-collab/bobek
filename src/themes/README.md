# Индивидуальные темы садов

Тема — это другой внешний вид сайта одного сада при том же движке.
Админка, разделы, новости, документы, поиск, двуязычие, версия для
слабовидящих и SEO остаются общими: сад работает с сайтом как раньше.

Обычные шаблоны (`src/templates`) сад выбирает сам в «Оформлении».
Индивидуальную тему назначает только владелец портала — в карточке сада,
блок «Индивидуальный дизайн». Пока тема назначена, она перекрывает шаблон;
если её выключить, вернётся шаблон, который выбрал сад. Данные не меняются.

## Что тема может заменить

| Часть       | Файл          | Получает                                   |
|-------------|---------------|--------------------------------------------|
| Главная     | `Home.tsx`    | `HomeProps` — те же данные, что и шаблоны  |
| Шапка       | `Header.tsx`  | `ThemeHeaderProps` — данные + `tools`, `nav` |
| Подвал      | `Footer.tsx`  | `ThemeFooterProps`                         |
| Оформление  | `theme.css`   | —                                          |

Каждая часть необязательна. Тема из одного `theme.css` просто перекрашивает
стандартный сайт: свои цвета, скругления, фон. Внутренние страницы
(документы, педагоги, новости, текст) всегда общие, но в цветах темы.

## Как сделать новую тему

1. Код темы — латиницей через дефис, например `aisha`.
2. Папка `src/themes/aisha/`: `theme.css` и нужные из `Home.tsx`,
   `Header.tsx`, `Footer.tsx`. Удобно начать с копии `obrazec`.
3. `src/themes/catalog.ts` — строка с кодом, названиями на двух языках и
   пояснением (видно в карточке сада).
4. `src/themes/index.ts` — строка в `PARTS` с компонентами темы.
5. `src/themes/themes.css` — `@import './aisha/theme.css';`.
6. Примерить: `THEME_PREVIEW=1` в `.env`, открыть
   `http://sad12.bobegim.local:3000/?theme=aisha`. `?theme=none` — без темы.
7. `pnpm test` — тесты скажут, если что-то забыто или нарушено.
8. Показать на тестовом саде: назначить тему 33nursat в карточке сада,
   посмотреть на телефоне и компьютере, потом назначить нужному саду.

## Правила — их проверяют тесты

**CSS действует только на свой сад.** Каждое правило в `theme.css`
начинается с `[data-theme='код']`. Имена `@keyframes` и `@font-face` —
с префиксом `код-`. `@import` внутри темы запрещён.
(`tests/unit/themes.test.ts`)

**Тема только рисует.** Никаких импортов из `@/server/*`, `@prisma/client`,
`next/headers`, `@/app/*`, никаких `'use server'`, `'use client'`, `process.env` и
`dangerouslySetInnerHTML`. Данные приходят готовыми; текст сада уже очищен
и выводится общими блоками из `@/components/site/blocks`.
(`tests/unit/themes.test.ts`)

**Обязательное остаётся.** В шапке темы должны стоять `tools` (версия для
слабовидящих и переключатель языка) и `nav` (меню). У самого `<header>` —
класс `site-header`: через него работает настройка сада «закреплять шапку». На главной — заголовок
`h1`. Подвал — элемент `<footer>`. (`tests/e2e/themes.spec.ts`)

**Цвета — токенами.** `rgb(var(--brand))`, `bg-brand`, `text-ink`, а не
`#264653`. Свои цвета темы задаются переопределением токенов в
`[data-theme='код'] { --brand: …; }`. Тогда палитра и контрастная версия
продолжают работать.

**Шрифты — только с казахскими буквами.** Перед тем как взять гарнитуру,
проверьте её измерением глифов (см. CLAUDE.md, «unicode-range…»).

## Что защищает сайт, если тема всё же сломалась

- **Страховка**: упала шапка, главная или подвал темы — посетитель видит
  стандартную версию этой части, а не страницу ошибки. На сервере тему
  заранее раскрывает `renderThemePart` (`src/server/themes/render.ts`) и
  ловит её ошибки; в браузере — `ThemeBoundary`. Поэтому своих клиентских
  компонентов в теме нет: меню, кнопки, увеличение фото — из движка.
  Владельцу портала приходит письмо (не чаще раза в час на тему и часть)
  с кодом ошибки; подробности — `journalctl -u vsesad | grep <код>`.
- **Версия для слабовидящих** снимает атрибут `data-theme`, и весь CSS темы
  перестаёт действовать: контрастная версия не зависит от темы.
- **Откат** — в карточке сада выбрать «Нет — шаблон сада».

## Предпросмотр

`?theme=код` работает только при `THEME_PREVIEW=1` — в разработке и в
сквозных тестах. На боевом сервере переменная не задана, иначе любой
посетитель мог бы открыть сад в теме, сделанной для другого сада.
